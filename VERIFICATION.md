# Verification and limits

The original 0.1.0 release recorded synthetic core tests, selected-folder copying in Opera, independent readback, fault checks, cancellation and two 520 MiB test inputs. Those were bounded development checks, not proof that every drive or browser works.

This source release reruns the deterministic tests and build. The only build change creates the verification directory automatically in a fresh checkout. Application behaviour is preserved. Only synthetic fixtures are included. A new browser or real-drive use still needs a small trial and retained originals.

The website's source and offline download routes returned 404 during the 29 October review. Release links are being repaired as part of this publication; the application and its limitations remain at the canonical Weidu page.
