What this first version includes

It inspects selected ordinary files and compares their contents locally. It can create checked copies in browsers that support folder saving, including recent desktop Chrome and Edge.

App libraries, system folders and backup images are left in place. This version does not open Windows backup images or recover deleted files. Choose readable folders on working drives.

The page sends no filenames or file contents to Weidu. There are no analytics or external services in the helper. Your selection lasts for this tab; save a report before closing it.

Read before making the copy

Keep this tab open until copying and checking finish. Make sure the destination has enough free space for the total shown above, plus room for temporary writes. Browser storage estimates cannot measure the free space on your chosen external drive.

These are copies of file contents and folder names. Original modification dates are listed in the report; copied files may show today’s date. Computer permissions, Finder tags and other extra file information are not preserved. Empty folders are not included. Keep existing backups and app libraries in their original form.

If you stop or a drive disconnects, COPY STATUS.txt in the new folder says INCOMPLETE. Completed files remain in it with a report. This first version starts a fresh folder when you try again; it does not resume an old job.
